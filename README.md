# 📖 Open-Book-AI

A RAG-based PDF chatbot that lets you upload any PDF and ask questions about it in plain English — like having an open book exam, always.

Built as part of my AI/ML learning journey. 🚀

---

## 🛠️ Tech Stack

- **Frontend** — HTML, CSS, JavaScript
- **AI** — Google Gemini API
- **PDF Parsing** — PDF.js
- **Backend** — Python, FastAPI, LangChain
- **Vector DB** — FAISS

---

## ✨ Features

- Upload any PDF and chat with it
- Semantic search finds relevant content
- Shows page citations with every answer
- Works 100% in the browser — no server needed

---

## 🚀 How to Use

1. Open `frontend/index.html` in your browser
2. Get a free API key from [aistudio.google.com](https://aistudio.google.com)
3. Paste your key in the app
4. Upload a PDF
5. Start asking questions!
